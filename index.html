Library

Add dictations from your own copy

Best layout: one folder per volume and one .txt per dictation, like Volume 1/Dictation 4.txt. Pick the folder that holds all the volume folders, or a single volume folder. Loose files named like "Volume 1 Dictation 4.txt" are sorted for you. For other names, type the volume name in the box below first and every selected file goes into that volume. A single file can also use # for volumes and ## for dictations, or be JSON.

The text lands in the passage box further down. Proofread it against the book, then save it here.

The library is stored in this browser only. Nothing is uploaded, so keep the book text out of any public repository.
